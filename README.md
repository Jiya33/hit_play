# 🍑 健身视频库

> 给 🍑 做的专属健身视频收藏夹 —— 想动的时候，打开就能练。

一个极简的健身教程视频管理页面，把散落在小红书、B站、抖音里的跟练视频收在一起，按部位打标签分类，随时筛选、随时开练。

**在线地址**：https://jiya33.github.io/hit_play/

---

## ✨ 能做什么

- **一键开练**：11 个精选默认教程，点一下直接跳转小红书 / B站 / 抖音
- **标签分类**：臀腿、腰腹、手臂、肩背、体态、燃脂，点标签即筛选
- **自定义标签**：想要什么分类自己加，比如「生理期友好」「10分钟速练」
- **自由增删**：觉得不好用的教程删掉，发现好用的加进来，名称也能改
- **复制链接**：一键复制地址，方便分享给朋友

## 📱 怎么用

手机、平板、电脑浏览器都能打开，界面会自适应屏幕大小。

加到手机主屏幕后，用起来跟 App 一样：
- **iPhone**：Safari 打开链接 → 分享 → 添加到主屏幕
- **安卓**：Chrome 打开链接 → 右上角菜单 → 添加到主屏幕

| 操作 | 位置 |
| --- | --- |
| 新增视频 | 右上角 ＋ 新增视频 |
| 编辑名称 / 改标签 | 卡片上 ✎ 名称 |
| 删除视频 | 卡片上 ✕ 删除 |
| 管理标签（增删） | 标签栏右侧「管理」 |

## 💡 一点说明

- 默认教程写在页面代码里，所有人打开都能看到
- 自己新增、删除、改名的记录保存在**当前浏览器**里，换设备或换浏览器不会同步
- 也就是说：这是你自己的一份清单，别人打开看到的是属于他们自己的

## 🛠 技术实现

- 单个 `index.html` 文件，原生 HTML + CSS + JavaScript，无框架、无依赖
- 数据持久化使用浏览器 localStorage
- 通过 GitHub Pages 免费托管
